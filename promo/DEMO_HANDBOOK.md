# 展示デモ手順（本番環境・まっさらから）

本番 https://agent.leadus-nova.com/ を空にして、**会議 → 議事録 → タスク → チャット → 成果物 → 矛盾の指摘 → 修正 → 完了 → Wiki** を一周見せる。
**人が手で入力できるところは全部手で入力する**。他の人（山田・佐藤）の投稿だけ、別のブラウザ窓でその人としてサインインして打つ。

- サインイン: `suzuki@aoba-beverage.example` / `aoba2026`（山田は `yamada@…`、佐藤は `sato@…`、パスワードは同じ）
- 事前に **2 つのブラウザ窓**を用意（例: Chrome の通常窓＝鈴木、シークレット窓＝山田）。映すのは鈴木の窓

---

## 0. 空にする（30 秒）

鈴木でサインイン → **エージェント**画面 → 右上の **「空にする」** → 確認 → 数秒で完了。

確認: ダッシュボード・検知結果・タスク・チャット・会議室・成果物・Wiki が全部ゼロ。

> 架空データ入り（Finding 15 件）に戻したいときは同じ画面の **「デモをリセット」**（約 1 分・LLM は呼ばない）。

**言うこと**: 「データは何もありません。ここから 1 つのプロジェクトを立ち上げます」

---

## 1. チャットで立ち上げを宣言（鈴木・手入力）

`チャット` → `#general` に打つ:

```
商品X（青葉りんごソーダ）の立ち上げを始めます。これからキックオフ会議をやります。
```

**言うこと**: 「普段どおりチャットに書くだけ。投稿がトリガーでエージェントが動きます」

---

## 2. 会議（鈴木・手操作）

`会議室` → **＋ 今すぐ会議** → タイトルを **商品X キックオフ** にして開始。

マイクの許可を求められたら許可。声に出して次を話す（ライブ字幕に出る。自分ひとりで全役をやってよい）:

| 話者 | セリフ |
|---|---|
| 鈴木 | 商品Xの立ち上げキックオフを始めます。今日は数字と担当を決めます |
| （田中役） | 製造から聞いた条件だと、初回ロットは300ケースが上限です |
| 鈴木 | 分かりました。初回ロットは300ケースで確定します |
| （山田役） | 売上見込は、第3四半期は0、第4四半期は450ケースで見ています |
| **鈴木** | **では第4四半期は450で確定。得意先から増量の要望が来ても、今期の見込みは450から変更しないでください** ← 後で効く |
| 鈴木 | 山田さん、売上見込表の初版を今週中に作ってライブラリに上げてください |
| 鈴木 | 田中さん、原価試算を来週の定例までにお願いします |
| 鈴木 | 佐藤さんは主要得意先3社にヒアリングして、結果を来週共有してください |

**「会議を終了して議事録を作る」** を押す。30〜60 秒で文字起こし → 抽出。

> 声を出せない場所なら、会議室の**メモ欄**に同じ内容を書いてもよい（メモも議事録に入る）。
> それも難しければ、事前に録っておいた `promo/video/flow.mp4` の会議部分を流す。

できるもの:

| 画面 | 結果 |
|---|---|
| 議事録サマリー（会議画面の紫のバナー） | 決定・タスク・懸念。各項目に根拠の発言（原文） |
| タスク | 担当つきで登録（山田・田中・佐藤） |
| Wiki | 「日付 + 商品X キックオフ」ページが自動作成 |

**言うこと**: 「人がしたのは終了ボタンだけ。議事録も起票も担当割り当ても書いていません」

---

## 3. 成果物の共有（山田の窓で手入力）

### 3-1. ファイルを作る
手元の Excel で、1 行目に `商品名 / 第1四半期 / 第2四半期 / 第3四半期 / 第4四半期`、2 行目に `商品X / 0 / 0 / 0 / 450` と入れて **商品X_売上見込.xlsx** で保存。
（作るのが面倒なら、事前に `450版` と `500版` の 2 ファイルをデスクトップに用意しておく）

### 3-2. アップロード
山田の窓で `成果物` → フォルダ **商品企画** → **アップロード** → そのファイル。

### 3-3. チャットで共有
`#general` に打つ（URL は成果物画面のファイル名を右クリック → リンクをコピー）:

```
売上見込表の初版を上げました。会議で決めた 第4四半期 450 で入れています <ファイルのURL>
```

**鈴木の画面で見せる**: 投稿にタスクのチップが付く（`⇢ 売上見込表の初版を…`）／成果物が **v1** になっている。

---

## 4. 決定に反する変更（山田の窓・ここが山場）

Excel で **第4四半期を 500 に変えて**保存 → 同じ手順でアップロード（**v2** になる）。
チャットには理由を書かずにこれだけ打つ:

```
見込表を更新しました <ファイルのURL>
```

30〜60 秒待つ（待てないなら鈴木の画面右上の **今すぐ巡回**）。

**鈴木の画面で見せる**: ダッシュボードに未対応の検知 → `検知結果`

| 見せどころ | 言うこと |
|---|---|
| 矛盾カード（confidence 0.85 前後） | 「人は誰も『確認して』と頼んでいません」 |
| 根拠 3 点（決定の原文・共有の投稿・セル差分 450→500） | 「なぜそう言えるかが全部出ます」 |
| 判定理由 ／「なぜこれを疑ったか」 | 「LLM を呼ぶ前にコードで絞った過程も見えます」 |

---

## 5. 差し戻しと修正

**鈴木の窓**: `#general` の山田の投稿にカーソルを合わせ、**引用アイコン**を押して打つ:

```
エージェントの指摘どおりです。会議で今期の見込みは変更しないと決めたので、第4四半期は会議の数字に戻してください。
```

**山田の窓**: Excel を 450 に戻して保存 → アップロード（**v3**）→ 引用返信で打つ:

```
直しました。会議の数字に戻しています。確認お願いします <ファイルのURL>
```

**言うこと**: 「今度は矛盾は出ません。決定どおりに戻したと判断しています。代わりに『レビュー中 → 完了』の提案が出ます」

---

## 6. 完了と Wiki（鈴木の窓）

`#general` に打つ:

```
確認しました。これで OK です。完了にしてください。
```

`検知結果` → **状態更新の提案** → **適用する**（ここは必ず手で押して見せる）。

最後に見せる画面:

| 画面 | 内容 |
|---|---|
| タスク詳細 | 決定 → タスク → チャット → v1 → v2（矛盾）→ v3（修正）→ 完了 が 1 本のタイムライン |
| 成果物 → その版の「差分」 | どのセルが誰にいつ変えられたか |
| Wiki「成果物: 商品X_売上見込.xlsx」 | 中身を構造化した本文（概要・表・主な数値）＋版の履歴・変更点・関連する決定 |

**締め**: 「人がしたのは、会議で話す・チャットに書く・ファイルを保存する・提案を承認する、の 4 つだけです」

---

## 困ったとき

| 症状 | 対処 |
|---|---|
| 矛盾が出ない | 右上の **今すぐ巡回** をもう一度。それでも出なければ Excel をもう一段変えて（例: 550）再アップロード |
| エージェントが動かない | `エージェント` 画面で自動巡回が ON か確認。OFF なら入れる |
| 途中で崩れた・時間が無い | **空にする** でやり直す（30 秒）。または **デモをリセット**（架空データ入り・Finding 15 件）に切り替えて、できあがった状態だけ見せる |
| ネットが不安定 | 事前録画 `promo/video/flow.mp4`（6 分）を流す。手順は同じ流れ |

所要時間: 0〜6 で 8〜12 分。短縮するなら **0 → 2（会議）→ 4（矛盾）→ 6（Wiki）**。

---

## 付録: ローカルで練習する

本番を触らずに同じ流れを試すなら、手元で空のサーバーを立てて、山田・佐藤の操作をコマンドで代行できる。

```bash
cd ~/ai-hack-2026
bash promo/demo_blank.sh start      # 空のサーバー（http://localhost:8790）
bash promo/demo_blank.sh meeting    # 会議を作り発言を入れる → Enter で終了
bash promo/demo_blank.sh share      # 山田が v1 を上げて共有
bash promo/demo_blank.sh break      # 山田が v2（450→500）を無言で上げる → 矛盾検知
bash promo/demo_blank.sh fix        # 差し戻し → v3 で修正
bash promo/demo_blank.sh done       # 「完了にしてください」
bash promo/demo_blank.sh state      # いまのタスク・検知・Wiki
bash promo/demo_blank.sh stop
```
