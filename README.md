# 進行管理エージェント

議事録・チャット・タスク・成果物を横断し、**「決定されたこと」と「実際に作られているもの」の食い違いを自律的に検知する** AI エージェント。AI HACK 2026 提出作品。

> この資料の第3四半期の数字、3日前の定例で「据え置き」と決まった内容と食い違っています。

人間が指示する前に動く。誰も依頼していない「突き合わせ」という監視業務を肩代わりする。

サンプルデータは全て架空の「青葉ビバレッジ株式会社」のもの（登場人物: 鈴木・山田・田中・佐藤・高橋）。

## 動かし方（3コマンド）

```bash
pip install -r requirements.txt
python -m app.cli seed      # 架空データを投入
python -m app.cli replay    # 検知までを時系列で再生（API キー不要）
uvicorn app.main:app        # UI を見る場合 → http://localhost:8000
```

`replay` は記録済みの LLM レスポンス（`fixtures/llm_cache.json`）だけで動くため、API キーなしで追体験できる。

実際に LLM を呼ぶ場合は `.env.example` を `.env` にコピーして OrcaRouter のキーとモデル名（会議室の文字起こしを使うなら `GEMINI_API_KEY` も）を設定し、`python -m app.cli run`（1回巡回）または `python -m app.cli watch`（5分間隔で巡回）を使う。

```bash
python -m app.cli evaluate  # 評価セット（10ケース）で検知率・誤検知・見逃しを出す
python -m app.cli cost      # コスト集計（全て high で回した場合との比較つき）
```

## アーキテクチャ

```
[Meet 文字起こし]   ──┐
[自作チャット]       ──┼→ ① コネクタ層 → ② 正規化（全ソースを Event に） → ③ 統合グラフ（SQLite）
[Excel 差分(SPO想定)] ──┘        SourceAdapter.fetch(since)                  events / tasks / links
                                                                                    │
                     ┌──────────────────────────────────────────────────────────────┘
                     ↓
      ④ 抽出（議事録 → 決定・タスク）        LLM: mid ＋ 引用の実在検証で幻覚を機械的に破棄
      ⑤ 紐付け（発言 → タスク、5段）          第1〜3段は LLM 不使用、第4段は埋め込み、第5段だけ LLM
      ⑥ 矛盾検知（決定 ⇔ 成果物の変更）      候補絞り込みと時系列ガードはコード、判定だけ high
                     │
        ┌────────────┴────────────┐
        ↓                         ↓
   confidence ≥ 0.8 → 通知    0.5〜0.8 → 確認キュー    （< 0.5 は記録しない）
```

| モジュール | 役割 |
| --- | --- |
| `app/connectors/` | 会議（自作 Meet / Drive API / fixtures）/ 自作チャット / Excel 差分。Confluence・Slack・SharePoint は同じ IF の空実装 |
| `app/stt.py` | 自作 Meet の音声文字起こし（Gemini Files API。会議終了時に話者ごとの録音を一括処理） |
| `app/excel_diff.py` | 行キーで対応付けるセル差分エンジン。行挿入で座標がズレても偽差分を出さない |
| `app/extract.py` | チャンク分割 → マスク → 抽出（mid）→ 引用検証 → 重複除去 → Task 自動生成 |
| `app/linker.py` | 明示参照 → 会話文脈 → 担当者 → 埋め込み → LLM の順で紐付け。紐付かないのも正解 |
| `app/detector.py` | タスク直結＋埋め込みで候補を絞り、時系列ガードを通ったものだけ high で判定 |
| `app/agent.py` | 5分ごとの自律ループ。取込 → 抽出 → 埋め込み → 紐付け → 検知 → アクション決定 |
| `app/llm/` | OrcaRouter クライアント（high→mid フォールバック・キャッシュ）/ マスキング / コスト記録 |

### 業務の流れとの対応

1. 会議をする → 文字起こしが取り込まれる（自作の会議室 `/meet`: WebRTC のビデオ会議。各参加者のブラウザが自分のマイクを録音し、終了時に Gemini で話者別に文字起こしして時刻順に統合。Drive 上の文字起こしドキュメント／fixtures も同じ Event になる）
2. 議事録から決定とタスクが自動で切り出され、タスクボードに積まれる（人力での作成・編集も可）
3. チャットの発言は、どのタスクの話かを自動判定して紐付く（「例の数字」も直前の文脈から解決）
4. 成果物は SharePoint に置き、更新した人がチャットにリンクを貼る → そのファイルがタスクの成果物として登録される
5. 成果物の版差分がタスクに直結し、元の決定と突き合わせて矛盾を検知する

### 設計上の要点

- **全ソースを `Event` に正規化する。** Excel の差分も「売上見込の商品Aの第3四半期が 1200 から 1500 に変更されました」という文になり、議事録の発言と同じ土俵に乗る
- **根拠のない指摘は作れない。** `Finding` は最低2件の Event id を持たないと生成できない（dataclass と DB 保存の両方で強制）
- **LLM に日付計算をさせない。** 「決定より前の変更」「新しい決定で上書き済み」はコードで判定する
- **取り込んだテキストは常にデータ。** 議事録やチャットに指示文が混ざっていても指示として解釈しない（プロンプトで境界を宣言し、抽出結果はスキーマに合わなければ破棄）
- **LLM 送信前にマスキング。** メール・電話・人名をプレースホルダに置換し、結果を人間に見せるときだけ復元する
- **書き込みは人間の承認が要る。** 通知は画面表示のみ。Slack・メールへの外部送信は実装しない

### モデルの使い分け（OrcaRouter）

| 処理 | tier |
| --- | --- |
| チャンク分割・差分の自然言語化・候補絞り込み・紐付け第1〜3段・時系列ガード・stalled / orphan 検知 | **LLM 不使用** |
| 決定・タスクの抽出、紐付け第5段 | mid |
| 埋め込み | embed |
| **矛盾判定** | **high**（ここだけは妥協しない） |

`python -m app.cli cost` が実測コストと「全て high で回した場合」の試算を並べて出す。

## 起動方式（ハイブリッド）

エージェントは **定期巡回（ポーリング）** を保険にしつつ、感度の高いイベントは **即時トリガー** で動く。

| イベント | 起動 |
| --- | --- |
| 会議の終了（文字起こし完了） | 即時 |
| チャットの投稿 | 即時（コストゼロの紐付けはその場で、残りは巡回で） |
| 成果物の新版（`fixtures/excel/` = SharePoint 代替フォルダの監視、または「成果物」画面からのアップロード） | 即時 |
| それ以外 | 30秒〜5分の定期巡回 |

どちらの場合も処理は増分（処理済みフラグ `processed` / `sync_state`）で、新しく入ったものだけを見る。

## 成果物の置き場所（SharePoint のドキュメントライブラリの代わり）

`fixtures/excel/` がライブラリのルート。フォルダ階層・任意のファイル種類・版管理（`<名前>_vN<拡張子>`）・タグ付け・タグでの絞り込み。
差分は xlsx がセル単位、docx / pptx / md / txt は本文の段落単位（`connectors/docs.py`、LLM 不使用）。それ以外の種類は「更新された」出来事だけを記録する。

| 方法 | 動き |
| --- | --- |
| **ブラウザで編集**（成果物 → ✎） | Excel Online の代わり（Luckysheet: リボン・数式バー・400+ 関数・書式・複数シート・結合・フィルタ・条件付き書式・グラフ・ピボット）。保存するとサーバーで xlsx に書き戻し、LibreOffice で数式を再計算して新しい版になる |
| **アップロード**（成果物 → ↑） | `.xlsx` を上げると `<名前>_vN.xlsx` として次の版になる |
| **監視フォルダで Excel を保存** | `.env` の `ARTIFACT_WATCH_DIR` に OneDrive の同期フォルダやデスクトップのフォルダを指定すると、本物の Excel で保存した瞬間に版として取り込む |

どの方法でも、自動巡回が ON なら数秒で差分 → 決定との突き合わせ → 検知まで自動で進む。
本物の SharePoint / OneDrive は `connectors/sharepoint.py`（Graph API 形式の空実装）を差し替える。

## 会議室（自作 Meet）

`/meet` はサーバー内の WebSocket でシグナリングする WebRTC のビデオ会議（外部サービス不要）。映像タイル・マイク/カメラ切替・**画面共有**・参加者一覧・会議内チャット・招待リンク。各参加者のブラウザが自分のマイクを録音し、「会議を終了」で全員分を Gemini Files API で話者別に文字起こしして時刻順に統合 → 議事録 → 次の巡回で決定・タスクに分解。

- 同じ PC で試すなら Chrome のタブを2つ開き、別の名前で参加する
- 別の端末から参加するには HTTPS が必要（`getUserMedia` の制約）。LAN なら `uvicorn --ssl-keyfile --ssl-certfile` で自己署名証明書を使う
